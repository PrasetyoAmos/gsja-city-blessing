Kelola jadwal, kegiatan, tim pelayan, dan teks situs. Masuk dengan token GitHub Anda.

Belum punya token? Begini cara membuatnya
  1. Buka github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: pilih Only select repositories → repo situs ini saja.
  3. Permissions → Repository permissions → Contents: pilih Read and write.
  4. Atur masa berlaku (mis. 90 hari), klik Generate token, salin, tempel di atas.

Token hanya disimpan di browser ini dan hanya dikirim ke api.github.com. Jangan bagikan token. Siapa pun yang punya token dapat mengubah isi situs; cabut di GitHub bila perangkat hilang.
